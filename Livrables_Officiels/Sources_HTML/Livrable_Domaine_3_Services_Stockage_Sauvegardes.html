1. Serveur de Fichiers & Partage Réseau Sécurisé (SRV-FILES) DMZ Interne (10.30.0.20)
📁 1.1. Architecture du Partage Samba / SMB

Hébergé en DMZ Interne sur la VM SRV-FILES (IP statique 10.30.0.20), le service SMB fournit un espace collaboratif sécurisé pour les utilisateurs de l'entreprise :

  • Arborescence : Dossiers dédiés /Partage/DocumentsEmploye et /Partage/Sauvegardes_Clement.
  • Contrôle d'accès : Authentification par identifiants locaux avec permissions strictes (lecture/écriture pour l'employé, aucun accès anonyme).
  • Administration sans interface graphique : Gestion distante assurée par SSH et PowerShell Remoting (WinRM ports 5985/5986).

2. Procédure de Sauvegarde Quotidienne Automatisée (M1-AUTO-01) Validation 100% Fonctionnelle
📜 2.1. Script Bash de Sauvegarde (backup-documents.sh)

Le script de sauvegarde déployé sur le poste client exécute les opérations suivantes :

  1. Vérification préalable de la joignabilité réseau du serveur (test TCP port 445 via Netcat).
  2. Montage dynamique du partage SMB via le fichier de credentials sécurisé.
  3. Synchronisation incrémentale rsync -avz --delete des documents de l'utilisateur.
  4. Génération de journaux d'audit horodatés et rotation automatique sur 7 jours.
  5. Démontage propre du partage CIFS en fin de traitement.

3. Plateforme Photo Immich sous Docker Compose (M1 & M2) Micro-services Conteneurisés
🐳 3.1. Justification Pédagogique de Docker en SISR
  • Complexité applicative : Immich est composé de 4 briques interconnectées (serveur Node.js, base PostgreSQL avec extension vectorielle pgvector, cache mémoire Redis et moteur d'IA/Machine Learning).
  • Déploiement IaC (Infrastructure as Code) :** L'ensemble de la pile est formalisée dans un fichier docker-compose.yml reproductible instantanément.
  • Isolation des ressources : Consommation RAM maîtrisée sur Proxmox VE et étanchéité face aux paquets du système hôte Debian.
📋 3.2. Architecture du docker-compose.yml (/opt/immich/)
# Extrait d'architecture de production : services: immich-server: image: ghcr.io/immich-app/immich-server:release ports: ["2283:2283"] depends_on: [database, redis] immich-machine-learning: image: ghcr.io/immich-app/immich-machine-learning:release redis: image: docker.io/redis:6.2-alpine database: image: docker.io/tensorchord/pgvecto-rs:pg14-v0.2.0
