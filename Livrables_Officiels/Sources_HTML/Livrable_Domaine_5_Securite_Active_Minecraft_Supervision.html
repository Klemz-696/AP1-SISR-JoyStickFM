1. Pot de Miel LAMP & Détection d'Intrusions (Mission 3) Défense Active (10.100.0.99)
🍯 1.1. Architecture du Honeypot Leurre

Conçu pour piéger et analyser les scans malveillants ciblant l'infrastructure, le faux serveur web est positionné en DMZ Externe (VM 11013, Debian 12, IP 10.100.0.99) :

  • Durcissement du leurre : Désactivation d'autoindex pour renvoyer une erreur 403 Forbidden sur la racine /, incitant les scanners à chercher des scripts d'administration.
  • Service d'alerting temps réel : Daemon systemd honeypot-alert.service scrutant en continu les journaux d'accès Apache pour intercepter les requêtes suspectes (ex : /wp-login.php, /admin-portal.php, /phpmyadmin).
  • Journalisation dédiée : Écriture des signatures d'attaque dans /var/log/honeypot-intrusions.log avec horodatage et adresse IP source.

2. Serveur Minecraft & Contournement du Filtrage DPI (Mission 2) DMZ Interne (10.30.0.22)
🎮 2.1. Ingénierie : Contournement DPI Académique

Le pare-feu du rectorat réalisant une inspection approfondie (DPI) sur les domaines Mojang/PaperMC pour bloquer la catégorie "Jeux", l'équipe a déployé une solution élégante :

  • Mode CUSTOM hors-ligne : Injection directe du binaire autonome server.jar 1.20.4 dans le volume persistant /opt/minecraft/data/ sous Docker Compose.
  • Sécurisation par VPN : Le port TCP 25565 n'est ouvert que sur l'interface WireGuard (10.200.100.0/24) et sur le LAN. Il est hermétique depuis le WAN et la DMZ Externe.
  • Gestion RCON : Élévation opérateur exécutée en ligne de commande : docker exec -i minecraft_ap1 rcon-cli op Klemz_696.
